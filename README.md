# Part Cost Estimator（机械零件四类统一报价技能）

`part-cost-estimator` 是一套面向非标自动化设备与机械零件采购/工程核价场景的 AI 技能（Codex Skill）。它能够根据机械工程图纸（PDF、PNG、JPG、CAD 导出图等）自动识别零件类别，按**加工件、钣金件、焊接件、型材组装件**四类差异化工艺模型提取计算驱动参数，并基于企业批准的 **LFAF 四类零件统一报价计算模板** 生成保留完整 Excel 公式、基础费率、厂商报价对比与分级人工复核记录的单一 `.xlsx` 报价工作簿。

---

## 1. 项目解决什么问题

在非标自动化设备开发、零件外协采购与工程成本核算中，传统人工报价与普通 AI 表格生成通常面临以下核心痛点：

1. **不同工艺类别混用同一套算法，导致成本失真**  
   机械零件涵盖机加工、钣金、焊接、工业铝型材组装等多种工艺。若将所有零件强行套用机加工“长 × 宽 × 高 × 密度”的块料算法，会忽略钣金展开面积与激光穿孔折弯、焊接件 BOM 净重与焊缝熔敷效率、型材标准定尺（如 6 m/支）整支采购分摊等真实成本驱动因素。
2. **多图纸人工识图与录表耗时长、易漏项**  
   面对成批零件图纸，工程师需要逐张核对标题栏、BOM、材质、数量、表面处理与视图尺寸，再手工录入对应工作表，效率低且容易出现图号、数量或尺寸摘录错误。
3. **普通 AI 直接输出死数字，破坏企业标准核价模板与公式**  
   常规 AI 生成的 Excel 往往重写表头或将金额写成固定常数，导致采购/成本人员无法在表格中调整材料单价、工时费率、税率或批量来动态重算，也无法继续手工增行。
4. **图纸模糊与工艺假设缺少风险分级与可追溯记录**  
   当图面存在尺寸冲突、遮挡、未标注展开尺寸或需估算材料利用率/切割速度时，若无明确的假设说明与复核清单，极易将“AI 临时估算值”直接当成正式报价依据。
5. **部分零件有厂商报价、部分未回价时，汇总对比口径失真**  
   若直接用“全量零件 AI 预估总额”减去“部分已回价零件的厂商报价总额”，会得出错误的差价结论。

**本项目的解决方案**：将 **AI 图面信息结构化提取** 与 **确定性的 Python OpenPyXL 模板生成器** 结合——AI 负责识图、分类、提取驱动量并记录不确定项；生成器严格基于 `LFAF_四类零件统一报价计算模板_20260807.xlsx` 写入数据、扩展公式与数据验证、生成同口径加权比价汇总，并输出带缩略图与单元格批注的 `图纸附件` 复核表。

## 2. 主要功能

### 2.1 四类零件独立成本核算模型
一张图纸对应一个零件报价行，系统先识别 `part_type`（`加工件`、`钣金件`、`焊接件`、`型材组装件`），再写入对应工作表：

| 零件类别 | 材料费计算逻辑 | 工序与附加费计算驱动项 |
| :--- | :--- | :--- |
| **加工件** | `密度 × 备料长 × 备料宽 × 备料高 × 材料单价`<br>（支持由成品长宽高自动加余量并向上取 5 mm 倍数推算备料尺寸） | 车床、铣床、磨床、钳工、其它、放电、快丝、慢丝、精雕机、CNC（按 `h` 计费）；夹头/治具费（按金额）；镀铬、热处理、阳极、发黑（按 `kg` 计费） |
| **钣金件** | `展开面积(m²) × 板厚(mm) × 密度 ÷ 材料利用率 × 材料单价` | 激光切割（切割长度、穿孔数、切割速度、穿孔秒数、每批切割准备工时）、折弯（折弯数、单刀分钟、每批折弯准备工时）、五金/件、手工分钟/件、表处费/件、其它费/件 |
| **焊接件** | `BOM 净重(kg/套) ÷ 材料利用率 × 材料单价` | 外购件/套、备料工时/批、组立工时/套、焊接工时（由焊缝长度、焊速、电弧作业率驱动）、焊材与气体费（由焊脚尺寸、截面积系数、熔敷效率、焊材单价、气体费率驱动）、打磨校形工时/套、表处/外协/套、检验包装/套 |
| **型材组装件** | 按 `ROUNDUP(数量 × 每套净长 ÷ (标准料长 × 排料利用率), 0)` 向上取整计算每批采购支数，再按 `采购支数 × 标准料长 × 理论重量(kg/m) ÷ 数量 × 材料单价` 分摊到每套 | 锯切（切断数/套、单刀分钟、每批锯切准备工时）、钻孔（钻孔数/套、单孔分钟）、攻牙（攻牙数/套、单孔分钟）、连接件/套、紧固件/套、装配分钟/套、补充焊接分钟/套、表处/外协/套、检验包装/套 |

### 2.2 完整保留企业模板公式、数据验证与基础参数
- **原样保留模板结构**：严格使用 `assets/LFAF_四类零件统一报价计算模板_20260807.xlsx`，保留全部字体、配色、边框、列宽、行高、Excel 表格（ListObject）、自动筛选与打印页面设置。
- **全公式驱动**：材料重量/用量、材料费、各道工序费、未税单价、税金、含税单价、含税总价全部保留 Excel 原生公式，打开工作簿自动重算（`fullCalcOnLoad = True`）。
- **集中参数管理**：税率（当前批准值 `13%`）、综合加成率（默认 `0%`）、17 种常用材质单价与密度、各工序标准工时费率统一存放在 `基础参数` 工作表，修改任一参数即可联动更新全表。
- **自动材质标准化与下拉校验**：自动将 `6061`、`AL6061`、`A6061`、`铝6061` 等标准化为模板定义的 `A6061T6`，并为材质列、数量列、材料利用率列、复核状态列自动挂载 Excel 数据验证（Data Validation）。

### 2.3 同口径厂商报价对比与加权汇总
- **明细行比价**：四类计算表均包含 `报价对比` 区。当填入 `厂商报价(未税)` 时，自动通过公式计算 `差价 = AI预估未税 - 厂商报价(未税)` 与 `占比 = 差价 / AI预估未税`（正值表示 AI 预估较高，负值表示 AI 预估较低）；未提供厂商报价时，`差价` 与 `占比` 保持空白，绝不将空白报价当作 `0` 处理。
- **统一汇总加权比价**：`统一汇总` 工作表同时输出：
  - **全量汇总**：所有零件的图纸行数、报价数量、AI 预估未税总额、税金总额、含税总额；
  - **可比口径汇总**：仅针对已填写 `厂商报价(未税)` 的零件行，按订单数量加权计算 `可比AI预估未税`、`厂商报价未税`、`差价` 与 `差价占比`，避免全量 AI 预估与部分厂商报价错位对比；当单类零件超过 500 行时自动扩展汇总公式范围。

### 2.4 分级人工复核与 `图纸附件` 追溯
- **三级风险判定**：所有识别冲突、缺失关键输入或使用默认工艺参数的项，自动归类为 `high`（高）、`medium`（中）、`low`（低）三个等级，并在对应零件行的 `复核状态` 列自动标记为 `高风险`、`待复核` 或 `无需复核`。
- **单元格批注提醒**：存在复核事项的零件，其计算表中的 `产品图号` 单元格会自动写入 `LFAF AI` 批注，鼠标悬停即可查看问题、AI 假设、成本影响与人工确认动作。
- **`图纸附件` 专表**：工作簿第 8 张表自动生成“一图一行”的复核清单，包含风险等级底色高亮、编号合并的异常说明、来源文件路径，并支持直接嵌入 PNG/JPG 图纸预览缩略图。
- **安全防覆盖输出**：默认输出至第一份图纸所在文件夹，命名为 `LFAF_四类零件预估报价明细_YYYYMMDD.xlsx`；若同名文件已存在，自动递增生成 `_v002`、`_v003`，不覆盖历史报价文件。

## 3. 安装方法

### 3.1 仓库目录结构

```text
part-cost-estimator/                                           # 技能主目录
├── LICENSE                                                    # MIT 开源许可证
├── README.md                                                  # 技能说明文档（本文件）
├── SKILL.md                                                   # 技能核心指令与工作流规范
├── agents/
│   └── openai.yaml                                            # 技能界面配置与默认提示词
├── assets/
│   ├── LFAF_四类零件统一报价计算模板_20260807.xlsx              # 批准的标准报价 Excel 模板
│   └── icon.svg                                               # 技能图标
├── references/
│   └── four-category-inputs.md                                # 四类零件计算输入字段与审核字典
└── scripts/
    └── generate_cost_workbook.py                              # 报价工作簿生成脚本
```

### 3.2 Python 环境与依赖安装

- **Python 版本要求**：Python `3.9+`
- **依赖库安装**：

```bash
pip install openpyxl pillow
```

> 说明：`openpyxl` 用于加载标准模板、扩展表格公式、配置数据验证和写入批注；`pillow` 用于在 `图纸附件` 工作表中缩放并嵌入 `.png` / `.jpg` 图纸预览图。

### 3.3 安装到 Codex 技能目录

将 `part-cost-estimator` 技能目录复制（或将同级打包的 `part-cost-estimator.zip` 解压）到本机 Codex 的 `skills` 目录下：

- **Windows (PowerShell)**：

```powershell
New-Item -ItemType Directory -Force -Path "$HOME\.codex\skills" | Out-Null
Copy-Item -Path ".\Skill\part-cost-estimator" -Destination "$HOME\.codex\skills\part-cost-estimator" -Recurse -Force
```

- **macOS / Linux**：

```bash
mkdir -p ~/.codex/skills
cp -R ./Skill/part-cost-estimator ~/.codex/skills/part-cost-estimator
```

安装完成后，Codex 会自动加载 `part-cost-estimator` 技能。

## 4. 使用方法

### 4.1 在 Codex / AI 助手中对话使用（推荐）

在对话中直接提供机械图纸文件（支持 `.pdf`、`.png`、`.jpg`、截图或已导出可读预览的 CAD 图纸），并通过 `$part-cost-estimator` 或自然语言发起报价请求：

- **基础图纸报价**：
  > 使用 `$part-cost-estimator` 识别 `D:\Drawings\K31\` 下的所有零件图纸，按四类零件生成一份 LFAF 统一报价表。
- **带厂商未税报价对比**：
  > 用 `$part-cost-estimator` 给这 4 张图纸做成本估算，其中 `R002` 厂商未税报价 100 元，`UC1002001103_F008` 厂商未税报价 32 元，输出报价对比结果。
- **指定输出目录**：
  > 请用 `$part-cost-estimator` 核算这批图纸成本，最终 Excel 保存到 `D:\Quotes\202610\`。

**AI 自动执行的 6 步标准流程**：
1. **收集图纸与报价信息**：读取图纸文件（若 CAD 原生格式无法直接解析，会提示提供 PDF/图片导出图）。
2. **提取并核对图面信息**：依次读取标题栏、材质、数量、技术要求、BOM 与各视图尺寸，比对潜在冲突并生成 `review_items`。
3. **判定零件类别并准备专用参数**：严格对照 `references/four-category-inputs.md`，将每个零件归入 `加工件`、`钣金件`、`焊接件` 或 `型材组装件`，提取对应类别的驱动字段。
4. **生成结构化提取文件（JSON）**：汇总所有零件参数、厂商未税报价与人工复核事项。
5. **运行生成器脚本**：调用 `scripts/generate_cost_workbook.py` 写入模板并生成单一 `.xlsx` 文件。
6. **验证并交付工作簿**：校验 8 张工作表顺序、行数一致性、公式完整性、13% 税率、批注与复核状态，返回最终文件链接与核价摘要。

### 4.2 命令行独立运行（CLI 模式）

如果你已经准备好结构化的零件参数 JSON 文件，也可以在 `part-cost-estimator` 技能目录下直接调用生成脚本：

```bash
python scripts/generate_cost_workbook.py \
  --input-json /path/to/parts.json \
  --output /optional/output/dir_or_file.xlsx
```

**命令行参数说明**：
- `--input-json`（必填）：提取后的零件数据 JSON 文件路径。
- `--output`（可选）：指定输出的 `.xlsx` 文件路径或目标文件夹。省略时默认按以下优先级输出：
  1. JSON 顶层 `output_dir` 指定的目录（若提供）；
  2. 第一份本地图纸 `source_file` 所在的文件夹；
  3. 若无本地图纸路径，则保存在 `parts.json` 同级目录。
- `--template`（可选）：自定义模板路径，默认使用内置的 `assets/LFAF_四类零件统一报价计算模板_20260807.xlsx`。

### 4.3 模板内置材质与兼容规则速查

- **`基础参数` 内置材质代码（共 17 种）**：  
  `S50C`、`A6061T6`、`鋁`、`电木A級`、`電木B級`、`4Cr13`、`亚克力`、`铍铜`、`黃銅`、`H13`、`鋼S136H`、`鋼S136`、`鐵`、`Q235`、`SUS304`、`SUS316`、`镀锌板`。
- **自动材质别名映射**：  
  输入的 `A6061` / `6061` / `AL6061` / `铝6061` 自动映射为 `A6061T6`；`AL` / `铝` 自动映射为 `鋁`；`电木` 自动映射为 `电木A級`。
- **缺省与兼容保护**：  
  - 若未提供 `part_type`，脚本会尝试根据唯一类别专用字段（如 `unfolded_area_m2`、`bom_net_weight_kg`、`net_length_m_per_set`）自动推断类别并标记 `待复核`；若仍无法推断，则暂按 `加工件` 兼容处理并自动生成 `high`（`高风险`）复核项。
  - 若钣金切割速度、焊接作业率、型材标准长度等工艺参数未在图纸中标明，脚本会填入安全默认值以防 Excel 公式报错，同时自动将该字段记入人工复核清单。
